# HW10 - Multithreading and Synchronization
## Problem 1:
Write a pthread program to calculate the approximation of π. The method of calculating of the
approximation was introduced in the class in the MPI part (Also in slides). You need to
implement this method using pthreads. The number of threads and the number of terms required
to calculate the approximation should be specified in the command line.
To test your program, run it with different number of terms and different number of threads. You
should be able to see that the approximation is closer to the real value of π when you increase the
number of terms.
Increase the number of threads, and check how execution time reduces. To get the execution time
of a program, use time command to time a command. For example, the following command times
the execution time of ls command:
$ time ls /usr/bin
To see the execution time reduce, the number of terms should be large enough (e.g., more than 1
billion). In addition to the time used for computing of PI, the time used to launch the program, to
create the process, and to terminate the program is also a part of execution time of the program.
Only the computation of PI is parallelized; and only this part of execution time can be reduced. If
the computation of PI accounts for only a small portion of the execution time, reducing this part
of time cannot substantially reduce the total execution time.
Increasing the number of threads cannot reduce the execution time when the number of threads
exceeds the number of cores. Use command lscpu to list the cores in the computer.

- Solution code:
```c
#include <stdio.h>
#include <stdlib.h>
#include <pthread.h>

long nthreads;
long long num_terms;
double step;
double *partial_sums;

void *compute_pi(void *id) {
    long *myid = (long *)id;
    long tid = *myid;

    long long chunk = num_terms / nthreads;
    long long start = tid * chunk;
    long long end   = start + chunk;

    if (tid == nthreads - 1) end = num_terms;

    double x, local_sum = 0.0;

    for (long long i = start; i < end; i++) {
        x = (i + 0.5) * step;
        local_sum += 4.0 / (1.0 + x * x);
    }

    partial_sums[tid] = local_sum;
    return NULL;
}

int main(int argc, char **argv) {
    nthreads = strtol(argv[1], NULL, 10);
    num_terms = strtoll(argv[2], NULL, 10);

    pthread_t *thread_array = malloc(nthreads * sizeof(pthread_t));
    long *thread_ids = malloc(nthreads * sizeof(long));
    partial_sums = malloc(nthreads * sizeof(double));

    step = 1.0 / (double)num_terms;

    for (long i = 0; i < nthreads; i++) {
        thread_ids[i] = i;
        pthread_create(&thread_array[i], NULL, compute_pi, &thread_ids[i]);
    }

    for (long i = 0; i < nthreads; i++) {
        pthread_join(thread_array[i], NULL);
    }

    double pi = 0.0;
    for (long i = 0; i < nthreads; i++) {
        pi += partial_sums[i];
    }

    pi *= step;

    printf("%.15f\n", pi);

    free(thread_array);
    free(thread_ids);
    free(partial_sums);
    return 0;
}
```
- Usage example:
```bash
$ gcc -o pi_pthread pi_pthread.c -pthread
$ ./pi_pthread 4 1000000000
3.141592653589793
```
## Problem 2: Sort Integers Saved in a File
Implement an MPI program that sorts a set of 4-byte integer values in ascending order. The values
are saved in a file. When the program finishes, the sorted values should be saved in the same file.
The values are saved in binary format. Thus, library functions such as fread() and
fwrite()are used to read and write the file. File pathname can be provided to the program via
user input (scanf ()).
Use count sort. You can assume that the smallest value is 0 and the largest value is 999. So it is
safe to set counter array size to 1000. Use the similar methods to split the computation and
maximize parallelism (local counter array) as what was used in the pthread version, which has
been introduced in the class and the textbook.
To test your program, you can compile and use gendatai.c and checkdatai.c attached with this
assignment. You can run gendatai to generate the file containing random integer values. Then, you
run your program to sort the values in the file. After that, you run checkdatai to check whether the
values have been sorted in ascending order.
Gendatai needs you to provide the number of values and the file pathname in the command line.
Checkdatai only needs the file pathname. For example, to generate 5000 random values and save
them into ./file5kvalues, you can use the following command
./gendatai 5000 ./file5kvalues
To check whether the values are sorted in the file, you run command
./checkdatai ./file5kvalues.
Both tools report the sum of the values in the file. You need to compare the sums, in case your
program misses some values or includes extra values.
You can assume that all integers in the file can fit into memory. So you can malloc a buffer and
read all integers into the buffer before doing countsort.
You can assume that the number of integers is divisible by the number of processes used to do
contsort. So you don’t need to consider the remainders when you try to evenly distribute the data
and workload.

- Solution code:
```c
#include <stdio.h>
#include <stdlib.h>
#include <mpi.h>

#define MAX_VALUE 999
#define VALUE_RANGE (MAX_VALUE + 1)  /* 0..999 => 1000 values */

int main(int argc, char *argv[]) {
    int my_rank, comm_sz;
    char filename[256];
    int *data = NULL;        /* Full data buffer (used on rank 0) */
    int *local_data = NULL;  /* Local chunk on each process */
    long long n = 0;         /* Total number of integers */
    long long local_n = 0;   /* Number of integers per process */
    FILE *fp;

    MPI_Init(&argc, &argv);
    MPI_Comm_rank(MPI_COMM_WORLD, &my_rank);
    MPI_Comm_size(MPI_COMM_WORLD, &comm_sz);

    /* Rank 0 reads filename from stdin and broadcasts it */
    if (my_rank == 0) {
        if (scanf("%255s", filename) != 1) {
            fprintf(stderr, "Failed to read filename.\n");
            MPI_Abort(MPI_COMM_WORLD, 1);
        }
    }
    MPI_Bcast(filename, 256, MPI_CHAR, 0, MPI_COMM_WORLD);

    /* Rank 0 opens the file, reads all integers into memory */
    if (my_rank == 0) {
        fp = fopen(filename, "rb");
        if (fp == NULL) {
            fprintf(stderr, "Could not open file %s\n", filename);
            MPI_Abort(MPI_COMM_WORLD, 1);
        }

        /* Determine file size to know how many ints */
        if (fseek(fp, 0, SEEK_END) != 0) {
            fprintf(stderr, "fseek failed.\n");
            MPI_Abort(MPI_COMM_WORLD, 1);
        }
        long file_size = ftell(fp);
        if (file_size < 0) {
            fprintf(stderr, "ftell failed.\n");
            MPI_Abort(MPI_COMM_WORLD, 1);
        }
        rewind(fp);

        n = file_size / sizeof(int);

        /* Assume n is divisible by comm_sz as per problem statement */
        if (n % comm_sz != 0) {
            fprintf(stderr, "Number of integers (%lld) is not divisible by number of processes (%d).\n",
                    n, comm_sz);
            MPI_Abort(MPI_COMM_WORLD, 1);
        }

        data = (int *)malloc(n * sizeof(int));
        if (data == NULL) {
            fprintf(stderr, "Memory allocation for data failed.\n");
            MPI_Abort(MPI_COMM_WORLD, 1);
        }

        size_t read_count = fread(data, sizeof(int), n, fp);
        if (read_count != (size_t)n) {
            fprintf(stderr, "Error reading data from file.\n");
            MPI_Abort(MPI_COMM_WORLD, 1);
        }

        fclose(fp);
    }

    /* Broadcast total count of integers to all processes */
    MPI_Bcast(&n, 1, MPI_LONG_LONG, 0, MPI_COMM_WORLD);

    local_n = n / comm_sz;
    local_data = (int *)malloc(local_n * sizeof(int));
    if (local_data == NULL) {
        fprintf(stderr, "Rank %d: memory allocation for local_data failed.\n", my_rank);
        MPI_Abort(MPI_COMM_WORLD, 1);
    }

    /* Scatter data to all processes */
    MPI_Scatter(
        data,                  /* send buffer (only meaningful on root) */
        (int)local_n, MPI_INT, /* send count/type */
        local_data,            /* receive buffer */
        (int)local_n, MPI_INT, /* recv count/type */
        0, MPI_COMM_WORLD
    );

    /* Each process builds its own local counter array */
    int local_count[VALUE_RANGE] = {0};
    for (long long i = 0; i < local_n; i++) {
        int v = local_data[i];
        /* Problem states values are in [0, 999], so this should be safe */
        if (v >= 0 && v <= MAX_VALUE) {
            local_count[v]++;
        } else {
            /* If you want to be defensive: */
            fprintf(stderr, "Rank %d: value %d out of expected range [0, %d]\n",
                    my_rank, v, MAX_VALUE);
            MPI_Abort(MPI_COMM_WORLD, 1);
        }
    }

    /* Reduce all local counters into a global counter on rank 0 */
    int global_count[VALUE_RANGE];
    MPI_Reduce(
        local_count, global_count,
        VALUE_RANGE, MPI_INT,
        MPI_SUM,
        0, MPI_COMM_WORLD
    );

    /* Rank 0 reconstructs sorted data and writes back to the same file */
    if (my_rank == 0) {
        long long idx = 0;
        for (int value = 0; value <= MAX_VALUE; value++) {
            for (int c = 0; c < global_count[value]; c++) {
                data[idx++] = value;
            }
        }
        /* idx should now be equal to n */

        fp = fopen(filename, "wb");
        if (fp == NULL) {
            fprintf(stderr, "Could not open file %s for writing.\n", filename);
            MPI_Abort(MPI_COMM_WORLD, 1);
        }

        size_t write_count = fwrite(data, sizeof(int), n, fp);
        if (write_count != (size_t)n) {
            fprintf(stderr, "Error writing sorted data to file.\n");
            MPI_Abort(MPI_COMM_WORLD, 1);
        }

        fclose(fp);
        free(data);
    }

    free(local_data);

    MPI_Finalize();
    return 0;
}
```
